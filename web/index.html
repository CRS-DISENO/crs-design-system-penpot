Qué es

Un plugin que monta la base

CRS Design System es un plugin para Penpot. Se instala desde una URL pública y, cuando lo ejecutas dentro de un archivo, dibuja las páginas de presentación del sistema de diseño como marcos de Penpot, con las capas ya nombradas y ordenadas, listas para que las edites como cualquier otro contenido.

Hoy genera tres páginas de 1280 px de ancho. La 00 Portada presenta el nombre, el propósito del sistema y los cinco pilares. La 01 Índice arma el menú de secciones con una columna de estado. La 02 Marca deja el logotipo en sus tres variantes con su criterio de uso, el símbolo y el playhead del logotipo como recursos de interfaz, los tamaños mínimos, el área de respeto, las reglas de uso, los usos incorrectos, los fondos permitidos y las formas del logo como recursos.

Además de dibujar, deja dos piezas de infraestructura listas: una biblioteca compartida de colores y tipografías que el archivo reutiliza, y los tokens del sistema publicados como un único archivo JSON con color, tipografía y espacio. Ese archivo es la fuente única: la web y el plugin leen lo mismo, así que no hay dos verdades que se separen con el tiempo.

El sistema de diseño completo, con los materiales y los componentes ya aplicados, tiene su propia página: página del sistema de diseño.

Antes y después

Qué soluciona

Montar un sistema de diseño a mano en una herramienta vectorial cuesta horas y se desincroniza en cuanto alguien mueve una pieza. El plugin cambia el punto de partida: la base ya está puesta, con nombres seguros y con los valores en un solo sitio.

Antes

A mano

  • Horas colocando marcos, textos y colores pieza por pieza, página por página.
  • Nombres de capa improvisados que nadie encuentra dos semanas después.
  • Colores y tipografías repetidos a mano: cambiar un azul obliga a buscarlo en cincuenta sitios.
  • Cada persona arma su versión y ninguna coincide con la de al lado.
  • Los valores del sistema viven en un documento aparte que la web no lee.
Con el plugin

En un clic

  • La base sale en un clic: tres páginas de 1280 px con el contenido ya escrito.
  • Nombres seguros y consistentes desde el primer trazo.
  • Una biblioteca compartida de colores y tipografías que el archivo reutiliza.
  • Un solo archivo JSON de tokens que la web y el plugin leen igual.
  • Un valor se cambia una vez, no cincuenta.

Qué hay en cada página

El plugin escribe tres páginas dentro de tu archivo de Penpot. Cada una responde a una pregunta distinta del sistema: para qué sirve, qué contiene y cómo se usa la marca.

Por dentro

Cómo funciona

Cuatro pasos, en lenguaje llano, con lo que pasa en cada uno.

  1. 1 Instalas el plugin una vez. Pegas la URL del manifest en el gestor de plugins de Penpot. Penpot descarga la interfaz y el código desde GitHub Pages y deja el plugin disponible en el menú.
  2. 2 Decides el logotipo. Arrastras el SVG de tu logotipo sobre la ventana del plugin. La interfaz lo lee en tu navegador y se lo pasa al plugin. Si no arrastras nada, se usan los tres SVG oficiales que viajan dentro del plugin.
  3. 3 El plugin dibuja. Crea los marcos en las tres páginas, nombra cada capa con la regla segura y arma la biblioteca compartida de colores y tipografías. Todo con layout flexible: nada queda clavado a una coordenada.
  4. 4 Los valores quedan en un archivo. Los tokens de color, tipografía y espacio se publican como un único JSON. La web del sistema y el plugin leen ese mismo archivo, así que lo que ves en una y en otro coincide.
Instalación

Instalar en cinco pasos

No hay cuenta, ni registro, ni descarga de archivos. Se instala con una URL.

  1. 1 Abre tu proyecto en Penpot. Sirve la versión de nube y la de escritorio, siempre con soporte de plugins.
  2. 2 Abre el gestor de plugins. Con Ctrl + Alt + P y elige la opción de instalar un plugin por URL.
  3. 3 Pega la URL del manifest. Es la dirección del bloque de abajo, sin nada más.
  4. 4 Confirma y abre el plugin. Aparecerá como CRS Design System en el menú de plugins del archivo.
  5. 5 Genera. Arrastra tu logotipo si quieres usar el tuyo, pulsa generar y espera unos segundos: verás las tres páginas y la biblioteca compartida.
URL del manifest https://CRS-DISENO.github.io/crs-design-system-penpot/manifest.json
GitHub Pages tarda un poco. Cuando se publica una versión nueva, el servicio que sirve la URL necesita un momento para tenerla lista. Si el manifest no responde justo después de un cambio, espera un minuto y vuelve a intentarlo: no hace falta reinstalar nada.
El campo version no es la versión del producto. Dentro del manifest.json, el campo version vale 2 porque indica la versión del esquema del manifest. La versión del producto se lee en el propio plugin: la raíz del repositorio sirve siempre la versión vigente.
Preguntas frecuentes

Lo que se pregunta siempre

Diez respuestas cortas. Si falta la tuya, está el enlace para escribir al final.

¿Necesito una cuenta?

No. El plugin se instala desde una URL pública y se ejecuta dentro de tu archivo de Penpot. No hay registro, ni cuenta de CRS, ni clave que recordar. Lo único que necesitas es un Penpot con soporte de plugins.

¿Funciona en la nube y en la versión de escritorio?

En las dos. Necesita Penpot 2.5 o superior, que es la versión con soporte de plugins, y salida a internet la primera vez para leer la URL del manifest.

¿Qué son los tokens y para qué sirven?

Son los valores del sistema (color, tipografía y espacio) guardados en un único archivo JSON. Sirven de fuente única: la web y el plugin leen el mismo archivo, así que un valor se cambia en un sitio y no hay que perseguirlo por toda la interfaz.

¿Puedo usar mi propio logotipo?

Sí. Arrastras el archivo SVG sobre la ventana del plugin y la interfaz lo lee con FileReader, dentro de tu navegador. El plugin no puede leer el disco, así que ese arrastre es la única vía, y el archivo no se sube a ningún servidor.

Si no arrastras nada, se usan los tres SVG oficiales que viajan dentro del plugin.

¿Sirve para otra marca que no sea CRS?

La mecánica sí: la estructura de las tres páginas, los nombres seguros y la biblioteca compartida sirven para cualquier marca. Lo que no es neutro es el contenido: los tokens, la tipografía, la paleta y el contenido de la página de marca son de CRS. Para otra marca hay que reemplazar esos valores a mano después de generar.

¿Qué no hace todavía?

No crea la pestaña de Tokens de Penpot, porque la API de plugins no la expone: los tokens se crean como biblioteca compartida y se publican como archivo JSON aparte. Tampoco lee el disco del usuario. No sincroniza cambios posteriores: genera una vez y lo que edites después es tuyo. Y por ahora dibuja tres páginas, no el sistema entero.

¿Dónde reporto un problema?

En los issues del repositorio en GitHub. Cuanto más concreto sea el reporte (versión que instalaste, qué esperabas y qué salió), más rápido se puede arreglar. También puedes escribir a info@crsdiseno.com.

¿Qué pasa si genero dos veces en el mismo archivo?

Se crean otras tres páginas nuevas; las anteriores no se borran solas. Lo más limpio es generar en un archivo vacío y después mover lo que necesites, o borrar las páginas viejas a mano antes de volver a generar.

¿Puedo editar lo que genera?

Sí, son marcos y capas normales de Penpot: cambias textos, mueves piezas y renombras capas como en cualquier archivo. Lo que no vuelve atrás es el vínculo con los tokens: si cambias un color a mano en el lienzo, el archivo JSON no se entera.

Limitaciones

Lo que no hace, dicho claro

Conviene saberlo antes de instalar. Ninguna de estas cosas es un fallo escondido: son límites conocidos.

  • La API de plugins de Penpot no expone la pestaña de Tokens, así que los tokens se crean como biblioteca compartida y se publican como archivo JSON aparte.
  • El campo version del manifest.json es la versión del esquema (2), no la del producto.
  • El plugin no lee el disco del usuario: el logotipo entra arrastrando el SVG sobre la ventana y se lee en el navegador.
  • Tres páginas y siempre de 1280 px de ancho. No hay versión estrecha de las páginas generadas.
  • Una sola pasada: no sincroniza los cambios que hagas en el lienzo después de generar.
  • El contenido de marca y los tokens están pensados para CRS. Otra marca exige reemplazar valores a mano.
  • Requiere Penpot 2.5 o superior con soporte de plugins. Sin eso, el gestor de plugins ni aparece.
